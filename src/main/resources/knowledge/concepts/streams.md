# Streams

Mixpla is **about streams**. A stream is a live audio experience a listener joins by link. The
product is not “radio” in the abstract — radio is one kind of stream.

# Kinds of stream

* **Brand radio** — a continuous stream that belongs to a brand. Someone starts it; it runs
  indefinitely from a programmed script, with an AI DJ between tracks. See the brand-radio workflow.
* **One-time stream (OTS)** — an ephemeral stream on its own link. It plays one script once from the
  moment it starts, then ends. See the one-time-stream workflow.

Both kinds reuse the same agenda, emission and aivox playout machinery; they differ in lifecycle,
routing identity and how they start (manual start vs cold-start on first listener).

# In Mixdeck

The **Streams** page (formerly Overview) is where an owner sees all of their streams — radio and OTS —
at a glance.
