# Artist submissions

Getting a track on air runs through the public brand chat, not Mixdeck. Eligibility is the `artist`
label on the listener: without it the upload and import tools refuse.

# Paths

* Chat upload — the file is posted to the temporary upload endpoint, then the DJ saves it to the
  catalog and queues it for broadcast with a spoken intro generated by TTS.
* Suno import — the track is fetched from Suno and lands in the same temporary-file step as a chat
  upload.

# After submission

A chat submission creates the share directly, bypassing Mixdeck's path. jesoos attaches the `new`
priority label so the track is floated to the front of the next agenda rebuild once the owner
accepts the share; the label is cleared after it is picked up, so a later rebuild does not float it
again.
