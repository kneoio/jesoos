# Public brand chat

Listener-facing WebSocket DJ chat per brand, with an OTS branch for event guests. Authentication is
by email OTP.

# Tools

Catalog search, play-with-intro, upload, ads, events and listener memory.

This is not the Ask chat: Ask is a separate package, WebSocket and agent.
